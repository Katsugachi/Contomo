# Contomo Preview
A duolingo style ladder climbing pomodoro timer co authored with claude.
## What is it?
Contomo is a focus timer tailored for the modern endless tasks of assessments and homework in highschool specifically. The timer implemented ranked mechanics and task noting to allow for 2-13x more effective work to be done in a set amount of time.
<br>
Link: https://katsugachi.github.io/Contomo/ <br>
Run locally by downloading `index.html`; you can rename it to whatever you want just keep the line ending (.html); e.g contomo.html <br><br>

Local app but secure: Heavy anticheat is enabled; when suspicious activity is detected, an embedded local AI model is deployed silently and conducts a comprehensive check of all your tasks ensuring its fairly earned. The model cannot be pried out and is part of the app - it will work with or without internet as it lives in the app in both local and web versions. XP values are encrypted so you cannot change it; it will fix itself.
